# Data Boundaries

## Public-safe data
- Published vehicle summaries
- Published package summaries/details
- Published destination content
- Published offers
- Public blog/CMS content
- Aggregated review data approved for public display
- Public contact/support information

## Never public by default
- Driver phone/private identity documents
- Internal vehicle notes
- Cost/margin data
- Staff records
- Internal booking notes
- Payment reconciliation metadata
- Customer private details
- Audit logs
- Private documents
- Provider secrets
- Webhook secrets

## Customer-only
- Own booking details
- Own invoices/documents
- Own payment state
- Own cancellation/modification request status

## Admin-only
Operational data according to role/permission.
